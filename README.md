## Installation
* Set up Python virtual environment in Windows:
1. python -m venv .venv
2. .venv\Scripts\activate
3. pip install -r .\requirements.txt
4. Look at requirements.txt to find out which Python libraries are needed for this course

* Get OpenAI api_key:
  
  Create your account and generate api_key from https://platform.openai.com/settings/organization/api-keys.
  Note: The Free ChatGPT plan only gives you access to GPT-3.5 in the web UI (chat.openai.com), not API usage.

* ChatGPT prompts used: I have used 4 different ChatGPT tabs to seek help with Python, GitHub, OpenAI, and prompting.

## Guidelines
* Write clear and specific instructions
* Give the model time to think
* Use delimiters for input
  
## Iterative prompt development
* Prompt development is an iterative process, don't expect your prompt to be perfect on the first try.
* Keep experimenting/reiterating until you get the desired output.
